Get started

Three steps, then ask your AI tool

enocone's MCP server teaches Claude Code, Cursor or any MCP client the flow format, lets it explore your app, and run and publish what it writes.

1Install
On macOS or Linux, with Homebrew. Then download Chromium for browser steps. 
$ brew tap driftwerk/tap
$ brew install enocone
$ enocone install-browsers
2Connect your project
In your repository: enocone.toml, a CI workflow that publishes here, and .mcp.json for your AI tool. 
$ enocone init --name shop \
    --hub {{ORIGIN}}
$ enocone login
3Ask for flows
Open your AI tool in the project. It drafts flows for people to review here, then implements them once approved. 
# in Claude Code or Cursor
"Design flows for the checkout
 feature, with mockups"

The full guide: enocone on GitHub. Create the project here and link it to your GitHub repository so CI publishes without a secret.

Open source

Rather keep flows on your own server? One command.

enocone serve is everything this site runs: one binary, one data folder, Caddy in front for HTTPS.

$ ENOCONE_PUBLIC_URL=https://flows.example.com \
  ENOCONE_OWNER_EMAIL=you@example.com \
  enocone serve
